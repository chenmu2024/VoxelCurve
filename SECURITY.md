# Security Policy

## Reporting a vulnerability

Do **not** publish exploit details, credentials, tokens, private files or other sensitive security information in a public GitHub Issue.

Check the repository **Security** tab for GitHub private vulnerability reporting or other private reporting options that may be enabled for the project.

If no private reporting channel is available, do not disclose working exploit details publicly. Contact the repository owner through the contact methods made available on their GitHub profile.

## Scope

Relevant reports include vulnerabilities affecting:

- code served from `voxelcurve.com`;
- generated download files;
- client-side storage or URL state;
- cross-site scripting or injection;
- dependency or build-chain security;
- Cloudflare deployment configuration.

Ordinary geometry mistakes, browser layout bugs and export compatibility problems should use the public Issue templates instead.

## Supported version

VoxelCurve is a continuously deployed static site. Security fixes apply to the current production version on `voxelcurve.com`.
