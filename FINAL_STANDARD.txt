# 1. 最终项目定义

VoxelCurve 不做 Minecraft 综合内容站。

网站只解决：

> **Minecraft 建筑中的曲线和几何形状如何转换成可以真正施工的方块蓝图。**

核心产品不是：

> Circle 图片生成器。

而是：

> **Guided Block Building Tool**

用户输入尺寸后，不仅得到 Blueprint，还应该知道：

- 从哪里开始；
- 当前这一行放几个方块；
- 方块位于什么位置；
- 中间空多少格；
- Dome 当前是哪一层；
- 已经完成多少；
- 还需要多少材料。

一句话产品定位：

> **Turn Minecraft curves into exact, guided block-by-block building plans.**

# 25. Circle 中心定义

对于：

```text
N × N
```

中心：

```text
cx = (N - 1) / 2
cy = (N - 1) / 2
```

Odd size：

例如：

```text
21×21
```

中心位于一个 block。

Even size：

例如：

```text
20×20
```

中心位于中间四个 block 之间。

这一规则全站一致。

---

# 26. Filled Circle

每一个 block 使用中心点判定。

```text
dx = x - cx
dy = y - cy
```

有效半径：

```text
R = N / 2
```

基础判定：

```text
dx² + dy² <= R²
```

然后经过：

- symmetry check
- bounds check
- duplicate check

---

# 27. Thin / Thick Circle

Thin 不使用一套完全不同逻辑。

采用：

```text
Outer Disk
-
Inner Disk
```

外半径：

```text
R_outer = N / 2
```

内半径：

```text
R_inner = max(0, R_outer - thickness)
```

Thin：

```text
thickness = 1
```

然后执行连通性修正。

# 30. Oval 算法

使用：

```text
(dx/Rx)² + (dy/Ry)² <= 1
```

其中：

```text
Rx = Width / 2
Ry = Height / 2
```

Thin/Thick：

仍然为：

外部 Ellipse - 内部 Ellipse。

# 31. Dome 算法

Dome 基于 Ellipsoid。

禁止建立：

```text
N × N × N
```

完整 voxel array。

内部使用：

```text

↓
Row
↓
Span
```

按 layer 生成。

这样：

- 内存低；
- 移动端稳定；
- TXT 容易生成；
- Litematic 容易展开。
